# Newsletter Templates

Four templates, one per content lane. All share the Field Notes brand framing and a structural spine: issue label → title → dek → front-loaded payoff → scannable body → "where this goes" close.

## Pick the right template

| If you… | Use |
|---|---|
| Built or shipped something (a Skill, a video, a pipeline, a system) | [**Build Log**](build-log.md) |
| A new tool or release dropped and you're evaluating it | [**Teardown**](teardown.md) |
| Have one sharp idea this week, no big build | [**Field Note**](field-note.md) |
| Want to write a structural / economic / industry take | [**The Long Lens**](long-lens.md) |

## How to use them

Each template is in a code block at the top of its file. Copy the whole block, paste into your editor, replace `[FILL: …]` markers with your content, delete `GUIDE —` notes before publishing. The structure is a working default, not a fresh decision each week.

## Universal rules baked in

- **Front-load the payoff** — the takeaway or artifact lives near the top, never buried
- **Same block order every issue** — readers learn where things live
- **One idea per section, short headers** — scannable by header alone
- **Short paragraphs (2-4 sentences)** — white space is a feature
- **One bolded line per section** — sparingly, the line that matters most
- **Issue label up top** — `▶ FIELD NOTES · ISSUE №[X] · [TYPE]`
- **One CTA at the end** — same place every issue
- **Sign-off** — author byline + subscribe ask
